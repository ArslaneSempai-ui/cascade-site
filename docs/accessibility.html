Appendix F Accessibility ← Back to the findings

Two ways in, one arrival. Measured, not promised.

This page holds the site to the same rule as the product: nothing promised, only measured. The figures below are computed from this site's own stylesheet and structure — and each claim ends with the gesture that lets you check it, right now, on the page you are reading.

▸The keyboard is a first-class door

Every finding on the main screen is a plain address — a link to an anchor. The whole instrument navigates by keyboard alone: Tab reaches every control, Enter opens it, and the browser's back button walks your trail backwards, because each state you visit is a real place in the address bar.

The one small script on that screen only synchronises the animation clock and the tab title. Switch JavaScript off and every state still opens — the navigation is the address, not a handler.

Try it now: press Tab until the findings rail takes focus, then Enter. Then press Back.

▸Contrast, measured

Computed from this site's own palette, not asserted: body ink on this paper measures 11.1:1. The weakest text pairing anywhere on the site measures 5.6:1. The accessibility floor for body text is 4.5:1 — every pairing here clears it with room to spare.

And colour never carries a meaning alone: wherever the green marks something — a shackle, a plateau, a signature — a word or a shape carries the same meaning beside it.

▸Native parts, native semantics

The sections of every appendix are native disclosure elements — the browser provides the keyboard behaviour and the screen‑reader semantics, so there is no script of ours to get them wrong. Focus is always visible: every interactive element carries a focus ring drawn in the site's own ink, never suppressed.

Try it now: Tab through this very page — each section header announces itself and toggles with Enter or Space.

▸Motion that asks permission

Every transition on this site sits behind the reduced‑motion media query. When your system asks for less motion, the cascade holds still — the same figures, the same states, without the movement.

Try it now: switch on your system's Reduce Motion setting and reload — the page arrives already settled.

▸What this page does not claim

These claims are mechanical — ratios computed, anchors counted, media queries present — so we make them. What we do not certify is the lived experience: this site has not been through an audit by a person who uses a screen reader daily, and that is the only audit of that experience that counts. If your team runs one and finds a fault, it will be fixed and this page will say it was.
